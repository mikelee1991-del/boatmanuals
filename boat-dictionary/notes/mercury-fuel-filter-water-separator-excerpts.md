# Fuel filter / water separator — service & fix

**On this boat:** Mercury Verado 300 engine-mounted **water-separating low-pressure fuel filter** (O&M `8M0145543`, ESN `3B371488`).  
**Location:** under **top cowl**, **starboard aft**, near **bottom spark plug**.

## If you get a water-in-fuel / Guardian fuel warning

1. Idle / stop safely; key **OFF**; lanyard positioned so the engine cannot start.  
2. No smoking/sparks; ventilate; have an approved fuel container ready.  
3. Disconnect battery before opening the fuel system (Mercury precaution).  
4. Remove **top cowl**; find filter **starboard aft** near bottom spark plug.  
5. Inspect / replace the engine-mounted filter (procedure below).  
6. Also inspect for a **boat-mounted** separator on the tank→engine fuel line (not yet photo-confirmed on this HIN) — drain water or replace that filter if fitted.  
7. Reconnect, key to RUN, **check for leaks** before starting.  
8. If warning returns immediately → dealer fuel-system diagnosis.

## Replace the engine-mounted filter

1. Key OFF; battery disconnected; catch fuel in an approved container.  
2. Remove top cowl; locate filter starboard aft near bottom spark plug.  
3. Push in fuel-hose **release tabs**; disconnect hoses.  
4. Unplug **water-in-fuel sensor** harness (may land on a boat-mounted filter instead — follow the harness).  
5. Rotate filter **clockwise ~¼ turn** and lift out; drain into approved container.  
6. Light coat of Mercury **2-4-C with PTFE** on the grommet.  
7. Install filter; rotate **counterclockwise ¼ turn** to lock.  
8. Reconnect sensor + hoses until locked.  
9. Battery on; key RUN; inspect for leaks; then start and verify warning cleared / tell-tale normal.

## When to service (even without an alarm)

1. Check for water/contaminants on the Mercury maintenance schedule (low-pressure fuel filter icon on engine decal).  
2. After bad fuel, long storage, or hard start / stumble that smells like fuel contamination.  
3. Seasonal inspection: engine filter + any boat-mounted separator.
