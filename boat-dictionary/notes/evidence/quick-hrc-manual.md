# Quick HRC control-panel manual evidence

Photo of the physical **Quick** “Multipurpose Control Panel” installation/user manual cover onboard.

## Confirmed
| Field | Value |
|-------|--------|
| Brand | **Quick** (“High Quality Nautical Equipment”) |
| Document | Multipurpose Control Panel — Installation and User’s manual |
| Revision | **CE REV 005c** |
| Covered models | **HRC 1002 / 1004 / 1006 / 1008 C00** and **HRC 1002 / 1004 / 1006 / 1008 L D00** (L = LED torch variants) |
| Device type | Handheld wired remote with deck socket (2×2 button grid shown on cover art) |

## Implication for this hull
- This is the OEM doc for a **Quick HRC** handheld multipurpose remote — commonly used for **windlass** (also gangway/crane/ladder on other boats).
- Exact installed SKU (button count / torch “L” vs non-L) is still **UNVERIFIED** until we photograph the handheld or count buttons.
- Windlass **motor/gypsy brand** is still **UNVERIFIED** (Quick control does not by itself prove a Quick windlass winch — photograph the motor plate). Prefer Quick HRC manual for remote operation; keep Lewmar windlass PDF as alternate winch candidate only.
