# OM-QS — Quickstart & daily checklist

Print or save this page for the helm binder.

## Pre-departure (5 minutes)

1. **Visual walk-around:** bilge dry / pumps free; no fuel smell; propeller clear; ski pylon clear of lines.
2. **EPHS steering fluid:** reservoir between MIN and MAX (**CONFIRMED** part `8M6005909`). Owner photo previously showed level near MIN — check every outing until stable.
3. **Battery voltages (engine off):** ENGINE and HOUSE ideally ≥12.4 V resting; under 12.2 V → charge before relying on thruster/windlass.
4. **Kill-switch lanyard** clipped to operator and DTS base.
5. **Fuel / water / holding:** know approximate levels (tank 340 L fuel; ~80 L fresh; holding present).
6. **Handheld VHF** charged and aboard (**NOT INSTALLED:** fixed VHF).
7. **Safety gear:** PFDs for all, fire extinguisher, throwable, flares, first aid, anchor rode free to run.

## Power-up (cold start) — summary

Full detail: [`chapters/05-power-sequences.md`](chapters/05-power-sequences.md#cold-start-power-up-underway) (`OM-PWR-01`).

1. Battery switch(es) → **ON** (ENGINE + HOUSE as equipped).
2. Confirm no shore-power cord still attached if leaving the dock.
3. Helm master / house breakers as needed → Blue Sea loads (MFD, stereo) as desired.
4. Attach **lanyard**.
5. DTS lever → **NEUTRAL**.
6. Ignition ON → wait for VesselView / SmartCraft self-test / READY.
7. **START** — do not crank continuously more than OEM allows; pause between attempts.
8. Check tell-tale water, no alarms, steering assist present, Zipwake powers, Garmin GPS fix.
9. Thruster test momentary (clear people/lines); windlass free (clutch/brake set for underway).

## Underway essentials

| Control | Notes |
|---------|--------|
| DTS **DOCK** | Low-speed docking response |
| DTS **THROTTLE ONLY** | Neutral gear, throttle for wash / warming |
| DTS **TRANSFER** | Multi-engine feature — single engine: leave unused unless prompted |
| Zipwake **AUTO PITCH / AUTO ROLL** | Default automatic interceptors (**CONFIRMED**) |
| Sleipner thruster | Use in short bursts; watch house/engine voltage |

## Power-down — summary

Full detail: [`chapters/05-power-sequences.md`](chapters/05-power-sequences.md#normal-power-down-shutdown) (`OM-PWR-02`).

1. Idle in neutral; cool briefly after high load if OEM recommends.
2. **STOP** engine; ignition OFF; remove lanyard.
3. Electronics OFF (Garmin, Fusion, Zipwake as desired).
4. Bilge check; raw-water flush of engine if in salt (see Mercury O&M).
5. Battery switch OFF if leaving boat unattended (leave bilge circuit powered if boat design allows — **UNVERIFIED** exact switch topology; confirm at battery switch panel).
6. If on shore power: connect shore cord → AC breakers → confirm CRISTEC **ON** LED.

## Shore power (marina) — summary

Full detail: `OM-PWR-SHORE`.

1. Engine OFF; battery switches as desired for charging.
2. Shore cord → inlet → pedestal **last**.
3. Confirm **115 V / 60 Hz** panel indicator; RCD/MCB closed.
4. CRISTEC YPOWER `YPO12-25DE` shows charge stage LEDs.
5. Disconnect reverse order: pedestal first, then inlet.

## Emergency stops

- **Kill switch / STOP** — engine.
- **Battery switch OFF** — electrical fire (after stopping engine if safe).
- **Shore RCD (30 mA)** — trip = disconnect shore, investigate before reset.
- **Never** ignore continuous warning horn / overheat / low oil — return to idle, investigate.
