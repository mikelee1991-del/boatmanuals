# Fusion stereo (MS-RA70N) — operate & fix

**On this boat:** Fusion **MS-RA70N** at the helm (**CONFIRMED** faceplate).  
**Fuse:** Blue Sea **AN4 · 10 A**.  
**Manual:** `manuals/electronics/Fusion-MS-RA70-RA70N-Owners-Manual-EN.pdf`  
**Install:** `manuals/electronics/Fusion-MS-RA70-RA70N-Installation-EN.pdf`  
**NOT INSTALLED:** MS-RA210 (older binder guess / equipment-list Sound Pack line — superseded by faceplate).

NMEA 2000 (**N2K**) is on this faceplate — network audio control from a compatible MFD is possible if the drop is wired (**UNVERIFIED**).

## If it won’t turn on / no sound

1. Confirm **HOUSE** (and ENGINE if needed) battery switches **ON**.  
2. Check Blue Sea fuse **AN4 10 A** — replace with same ampacity if blown.  
3. On the stereo: press the **power** button (bottom-left of the button cluster). If already on, short-press power to **mute/unmute** per OEM behavior.  
4. **Turn the dial** to raise volume.  
5. Select the intended source (Bluetooth / radio / AUX / USB). Wrong source = silence.  
6. Bluetooth path: phone connected and **playing**; volume up on phone; re-pair if needed (see pairing below).  
7. Still dead with good fuse/voltage → check speaker wiring / amp protect; see `OM-TS-AUDIO`.

## Bluetooth pairing

1. Select the **Bluetooth** source.  
2. Make the stereo discoverable from its Bluetooth / connections menu (see RA70 OEM manual).  
3. On phone: Bluetooth on → find Fusion → pair.  
4. Start playback on the phone; set volume on the stereo dial.  
5. Turn discoverable **off** after pairing when the menu offers it.

## Daily controls (RA70 face)

1. **Power:** power button (red icon).  
2. **Volume / browse:** large left dial.  
3. **Menu / back / skip / play:** six-button cluster right of the dial.  
4. **Factory reset / soft reset:** follow RA70 OEM troubleshooting (do not use RA210-only menu paths).
