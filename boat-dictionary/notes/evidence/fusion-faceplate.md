# Fusion stereo faceplate evidence

Close-up of the helm Fusion head unit (wood-grain panel mount).

## Confirmed
| Field | Value |
|-------|--------|
| Brand | **FUSION** (Garmin Fusion) |
| Model | **MS-RA70N** (printed on faceplate upper right) |
| Bluetooth | Faceplate Bluetooth mark |
| NMEA 2000 | Faceplate **N2K** mark — this is the **N** (network) variant, not plain MS-RA70 |
| Mount | Flush in dark wood-grain helm panel |
| Status when photographed | Display off; black power lead visible in frame |

## Implication for this hull
- Earlier binder assumption of **MS-RA210** is **wrong for this HIN** — treat RA210 manuals as library-only / discarded candidate.
- Prefer `manuals/electronics/Fusion-MS-RA70-RA70N-Owners-Manual-EN.pdf` for operate/troubleshoot.
- N2K means Fusion-Link / MFD control over NMEA 2000 is **possible** if the network is wired (**wiring path still UNVERIFIED**).
