# OM-MAINT — Maintenance

Intervals below combine **Mercury / Zipwake / pump OEM** practice with vessel-specific notes. Always defer to the ESN-specific Mercury O&M and Beneteau CE handbook when they differ.

## Every outing
- EPHS fluid MIN–MAX (`8M6005909`)
- Tell-tale water after start
- Bilge & strainer glance (Flojet/Jabsco)
- Visual prop / anode / Zipwake blades when possible
- Kill lanyard condition
- Handheld VHF charged

## Every week / after heavy use
- Freshwater flush of Verado (salt)
- Rinse teak & hardware; light teak clean as needed
- Rinse thruster tunnel area if shallow-water ops
- Check battery voltages resting

## Monthly / monthly-ish
- Fuse panel visual (corrosion, wrong amperage)
- Windlass wash + light lube per brand manual
- Zipwake wipe + inspect for play/damage
- CRISTEC: confirm profile still matches batteries; inspect AC inlet gasket
- Test bilge float & nav lights

## Seasonal / annual (dealer or skilled DIY)
- Mercury service per hours/months (oil, filters, gear lube, plugs, impeller as due)
- Steering system inspection
- Fuel filter / water-separating filter if equipped
- Anodes replace when ≥50% depleted
- Thruster oil/prop check per Sleipner manual (model-specific)
- Holding tank / hose inspection
- Update Garmin + Fusion + Zipwake firmware when stable releases available
